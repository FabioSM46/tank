# Tank Game

Aztank is a top-down 2D tank shooter game developed using the Go programming language and the Ebiten game library. The goal of the game is to control your tank, destroy enemy tanks, and survive through multiple levels while avoiding obstacles and collecting power-ups.

## Game Overview

- **Type**: Top-down tank shooter
- **Objective**: Destroy enemy tanks while avoiding their attacks
- **Features**:
  - Player and enemy tanks with movement and shooting mechanics
  - Multiple levels with increasing difficulty
  - Obstacles and power-ups
  - Simple AI for enemy tanks
  - Collision detection for bullets, tanks, and obstacles

## Libraries and Tools

- **Go programming language**: The programming language used to develop the game
- **Ebiten game library**: A cross-platform 2D game development library for Go
